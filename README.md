# YouTube Subscribers Data Analysis 📊

## 📌 Project Overview
This project focuses on analyzing YouTube channel and video performance using Excel. The dataset contains information about video categories, countries, views, likes, comments, revenue, and subscribers. The goal is to identify performance trends and generate meaningful insights from the data.

## 🎯 Project Objectives
- Analyze YouTube video views and subscriber performance.
- Compare likes and comments across video categories.
- Understand country-wise and category-wise views.
- Analyze monthly views and trends.
- Compare revenue across countries and categories.
- Identify top-performing categories and videos.

## 🛠️ Tools & Technologies
- **Microsoft Excel**
- Data Analysis
- Pivot Tables
- Data Aggregation
- Charts and Dashboards

## 📈 Analysis Performed
1. Category-wise video likes analysis.
2. Country-wise and category-wise views analysis.
3. Category-wise likes and comments comparison.
4. Monthly views trend analysis.
5. Country-wise and category-wise revenue analysis.
6. Category-wise subscriber and video count analysis.
7. KPI analysis for YouTube performance.

## 💡 Key Learnings
- Learned how to organize and analyze a large dataset in Excel.
- Practiced using Pivot Tables to summarize data.
- Explored video performance across categories and countries.
- Understood how to analyze monthly trends and revenue.
- Improved data interpretation and analytical skills.

## 🚀 Project Outcome
This project demonstrates practical Excel data analysis skills and helps transform raw YouTube data into meaningful information for understanding video performance, audience engagement, subscriber distribution, and revenue trends.
